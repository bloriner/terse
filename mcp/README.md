# terse-mcp — MCP server for the Terse language

A [Model Context Protocol](https://modelcontextprotocol.io) server that lets AI
coding agents parse, evaluate, transpile, and token-count
[Terse](https://github.com/bloriner/terse) source. Stdio transport,
newline-delimited JSON-RPC 2.0, standard library only — no new dependencies.

## Run

From the repo root:

```bash
python -m mcp.server
# or
python mcp/server.py
```

The server reads JSON-RPC requests on stdin and writes responses on stdout
(MCP stdio transport). Protocol version: `2024-11-05`.

## Client configuration

Claude Desktop (`claude_desktop_config.json`):

```json
{
  "mcpServers": {
    "terse": {
      "command": "python",
      "args": ["-m", "mcp.server"],
      "cwd": "/path/to/terse"
    }
  }
}
```

Any MCP client that supports stdio servers works the same way: command
`python`, args `["-m", "mcp.server"]`, working directory set to the repo root.

## Tools

### `terse_eval`

Evaluate Terse source with the tree-walking interpreter.

```json
{ "source": "(add 1 2)", "gas": 100000 }
```
→
```json
{ "value": 3, "output": [] }
```

`gas` is optional (default `100000`) and always enforced by the interpreter —
infinite loops die with a structured `E205` gas-exhausted error, never a
hang. Failures return `{ "error": { "code", "message", "phase", "hint?" } }`,
never a traceback.

### `terse_transpile`

Transpile Terse source to readable, executable Python.

```json
{ "source": "(def sq (x) (mul x x)) (print (sq 9))" }
```
→
```json
{ "python": "# Generated by terse.to_python v0.1 ...\ndef sq_1(x_2):\n    return (x_2) * (x_2)\n_terse_result = _terse_print(sq_1(9))\n" }
```

### `terse_tokens`

Count tokens with `tiktoken` `cl100k_base` when importable, otherwise a
`ceil(len/4)` character estimate (the method used is always reported).

```json
{ "source": "(add 1 2)" }
```
→
```json
{ "tokens": 6, "method": "tiktoken-cl100k" }
```

### `terse_parse`

Parse Terse source and return the AST as JSON (tuples become lists).

```json
{ "source": "(add 1 2)" }
```
→
```json
{ "ast": ["add", 1, 2] }
```

## Safety notes

- Evaluation goes through the Terse tree-walking interpreter only. The
  server never `eval()`s Python.
- Gas limits are enforced on every evaluation; `gas` is capped at
  10,000,000 server-side.
- All errors — parse, runtime, transpile, internal — come back as
  structured `{ "error": ... }` payloads. Tracebacks never leave the server.
